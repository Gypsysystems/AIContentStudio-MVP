# Running on Replit

This project is a React 19 app built with Vite and Tailwind CSS.

## Development

The **Start application** workflow runs:

```sh
PORT=5000 pnpm dev
```

The Vite server binds to `0.0.0.0`, allows Replit's proxied preview host, and uses port 5000.

## Other commands

- `pnpm build` — create a production build
- `pnpm preview` — preview the production build locally
- `pnpm format` — format the source
